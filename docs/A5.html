Criação de subconjuntos e tabela de contingência

Análise descritiva

Para descrever aspectos importantes do conjunto de dados sumarizado, foi utilizada a função group_by para agrupar os dados em 2 grupos (prova 1 e prova 2), em seguida foi inserida a função summarise() que oferece uma análise descritiva resumida, contendo: média, mediana e desvio padrão da váriavel contínua (prova).

Para observar a distribuição de frequências da variável nota, foi gerado um histograma para cada prova, inserindo a função geom_histogram(). Adiante, os histogramas foram gerados em uma mesma imagem, utilizando a função plot_layout()do pacote patchwork().

notas |> 

  group_by(prova) |> 

  summarise(nota_mean = mean(nota),

            nota_sd = sd(nota),

            nota_med = median(nota))
# A tibble: 2 × 4
  prova nota_mean nota_sd nota_med
  <dbl>     <dbl>   <dbl>    <dbl>

media1 <- mean(notas1$nota)

media2 <- mean(notas2$nota)

library(ggthemes)

p1 <- notas1 |> 

  ggplot(aes(x = nota))+

  geom_histogram(bins = 5, fill = "darkorange", color = "white")+

  geom_vline(xintercept = media1, color ="black", linetype = "dashed") +

  scale_fill_canva()+

  theme_bw(base_size = 14)+

  theme(legend.position = "bottom")+

  annotate(geom = "text",

           x = 72,

           y = 7.5,

           label = "Mean")+

  ylim(0,10)+

  labs(y = "Frequency",

       x = "Notas",

       title = "Prova 1")

p2 <- notas2 |> 

  ggplot(aes(x = nota))+

  geom_histogram(bins = 5, fill = "darkcyan", color = "white")+

  geom_vline(xintercept = media2, color ="black", linetype = "dashed") +

  scale_fill_canva()+

  theme_bw(base_size = 14)+

  theme(legend.position = "bottom")+

  annotate(geom = "text",

           x = 72,

           y = 6.5,

           label = "Mean")+

  ylim(0,10)+

  labs(y = "Frequency",

       x = "Notas",

       title = "Prova 2")

library(patchwork)

(p1 + p2) + 

  plot_layout(guides = "collect",

              axes = "collect")
