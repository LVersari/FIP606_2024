4. Testando as premissas

Antes da execução da ANOVA é verificada as premissas: homogeneidade de variâncias e normalidade.

4.1 Teste de Bartlett

O teste de Bartlett é usado para verificar se as amostras têm homogeneidade de variâncias (variâncias iguais).

4.1.1 Pressupostos

O teste assume que as observações são independentes.

4.1.2 Hipóteses

Hipótese nula: as variâncias são iguais.
Hipótese alternativa: As variâncias são desiguais para pelo menos dois grupos.
