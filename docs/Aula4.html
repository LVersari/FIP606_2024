Importar dados

Nessa aula iremos aprender outra forma de importar os dados, através do pacote datapasta. Instalando o pacote, ele fornece mais opções na aba Addins. Por meio do Addins podemos copiar (Ctrl+C) algum dado, vetor ou tabela e colar dentro do chunk no documento R Quarto Markdown. Para colar essas informações, selecionamos o Addins e podemos selecionar Paste as conforme o que desejarmos, sendo vector uma coluna e data.frame como uma tabela.

No site R4PDE.net foi importado os dados pepper. Esses dados estão no formato largo, por isso, usando a função pivot_longerdo tidyverse para tranformar a tabela no formato longo.O gráfico deve ser feito com o formato longo.

Esses dados foram transformados em um gráfico usando o geom_pointe o geom_line. Para definir um nome para cada linha formada, usamos a função annotate.

pepper |> 
  pivot_longer(2:4,
               names_to = "epidemic",
               values_to = "inc") |> 
  ggplot(aes(t, inc, color = epidemic))+
  geom_point()+
  geom_line()+
  annotate(geom = "text",
           x = 10,
           y = 0.75,
           label = "1")+
  annotate(geom = "text",
           x = 25,
           y = 0.75,
           label = "2")+
  annotate(geom = "text",
           x = 47,
           y = 0.75,
           label = "3")+
  theme(legend.position = "none") #Isso é usado para tirar a legenda do gráfico
