1. Estatística Inferencial

A Inferência Estatística consiste de procedimentos para fazer generalizações sobre as características de uma população a partir da informação contida na amostra.

2. Dois grupos independentes

Carregamento dos dados a partir de planilha online (google drive), utilizando o pacote gsheet e a função gsheet2tbl.

library(gsheet)  
mg <- gsheet2tbl("https://docs.google.com/spreadsheets/d/1bq2N19DcZdtax2fQW9OHSGMR0X2__Z9T/edit#gid=983033137")

3. Visualização dos dados

library(tidyverse)  
mg |>       
  ggplot(aes(trat, comp))+      
  geom_boxplot()

O gráfico mostra um possível efeito do tratamento Mg2 na redução do comprimento das lesões.

Os dados apresentam uma baixa dispersão, indicando uma possível distribuição normal dos dados.

4. Teste de Normalidade

Foram utilizados diferentes médodos para averiguar se os dados apresentam uma distribuição normal.

Como:

Q-Q Plot, usando as funções qqnorm e qqline;

Histogramas, selecionando a função hist;

E aplicando o teste de normalidade Shapiro-wilk, a partir da função shapiro.test.

mg2 <- mg |>       
  pivot_wider(names_from = trat,                              
              values_from = comp) 
teste1 <- t.test(mg2$control, mg2$Mg2)    
shapiro.test(mg2$control)  

    Shapiro-Wilk normality test

data:  mg2$control
W = 0.93886, p-value = 0.5404
shapiro.test(mg2$Mg2)  

    Shapiro-Wilk normality test

data:  mg2$Mg2
W = 0.97269, p-value = 0.9146
hist(mg2$control)  

hist(mg2$Mg2)    

qqnorm(mg2$control)  
qqline(mg2$control)    

qqnorm(mg2$Mg2)  
qqline(mg2$Mg2)

Foi possível confirmar que os dados apresentam uma distribuição normal, utilizando as três formas de análises. No teste de Shapiro Wilk, o P valor é maior que o nível de significância adotado (⍺ = 5%), ou seja, a hipótese nula (de normalidade) não é rejeitada.

5. Teste de homocedasticidade

A função var.test foi usada para realizar o teste de homogeneidade de variâncias.

var.test(mg2$control, mg2$Mg2)

    F test to compare two variances

data:  mg2$control and mg2$Mg2
F = 0.67654, num df = 9, denom df = 9, p-value = 0.5698
alternative hypothesis: true ratio of variances is not equal to 1
95 percent confidence interval:
 0.1680428 2.7237436
sample estimates:
ratio of variances 
         0.6765394

A hipótese nula não foi rejeitada, há homogeneidade entre as variâncias das amostras.

A seguir, será adotado o Test t.

7. Dois grupos dependentes

carregou o conjunto de dados:

escala <- gsheet2tbl("https://docs.google.com/spreadsheets/d/1bq2N19DcZdtax2fQW9OHSGMR0X2__Z9T/edit#gid=1729131173")

7. Visualização

Plotou um gráfico bloxplot para visualizar o conjunto de dados.

escala |>       
  ggplot(aes(assessment, acuracia))+      
  geom_boxplot()

escala2 <- escala |>       
  select(assessment, rater, acuracia) |>       
  pivot_wider(names_from = assessment,                              
              values_from = acuracia)

8. Normalidade e Test t

Aplicou o test t e verificou a normalidade da distribuição dos dados.

shapiro.test(escala2$Unaided)  

    Shapiro-Wilk normality test

data:  escala2$Unaided
W = 0.7748, p-value = 0.007155
shapiro.test(escala2$Aided1)  

    Shapiro-Wilk normality test

data:  escala2$Aided1
W = 0.92852, p-value = 0.4335
var.test(escala2$Unaided, escala2$Aided1)   

    F test to compare two variances

Com base no teste de normalidade Shapiro-Wilk, concluiu que os dados não apresentam distribuição normal.

A seguir, pode ser aplicado um teste de comparação de grupos, não paramétrico.

9. Teste não paramétrico

wilcox.test(escala2$Aided1,              escala2$Unaided,              
            paired = TRUE)

    Wilcoxon signed rank test with continuity correction

data:  escala2$Aided1 and escala2$Unaided
V = 55, p-value = 0.005889
alternative hypothesis: true location shift is not equal to 0

O P-valor foi significativo, portanto não foi possível computar o valor de p exato com o de desempate.
